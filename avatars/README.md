# Melete's own profile pictures

The pictures here are the "Melete" category of the profile picture gallery, shown first.
They're part of this repository and its licence, and are copied into the image at
`/usr/share/melete/avatars`.

Each is a PNG, JPEG or WebP file directly in this folder, square, up to 5 MB (a few hundred
kilobytes is plenty). Files are listed by name, so number them to set their order
(`01-quill.png`, `02-lyre.png`…). Anything else here, this file included, isn't listed.
