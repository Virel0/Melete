Decision: A hero pick gives both its trailer and a clip of itself (file, start, 40 seconds), and
the app chooses which to play where; there's no preference for it. The clip is the file Play
would start (the episode the pick names, else the movie's file with the viewer's progress, else
the first file or the first episode on disk, specials last), from where the viewer left it, else
an eighth of the way in (the film's running time, else its probed length, else ten minutes).

Why: Apps lay previews out differently per screen (a hero, an idle screen), so the choice is
theirs; working the clip out on the server keeps every app's clip the same and saves each a
lookup.
