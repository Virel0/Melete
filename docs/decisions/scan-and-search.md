Decision: A movie or series library can be scanned and then searched (Scan and search): the library is scanned through the library task, so its new files are matched and probed before anything is searched for; then, each unless turned off, a Search all missing run for what's missing and one for upgrades of files below their cutoff, each for that library's titles alone, then the subtitles its films and episodes lack in the languages set for imports. A title is the library's when its folder is in it, or, without a folder yet, when its new files go there. A run already under way in the area is let finish first; one sweep at a time per library (the database's constraint), refused for music and while the library isn't responding. It's started by hand, never by the scan schedule. Each file and language is looked for once, and fetching stops at OpenSubtitles' daily downloads, so a sweep can be run again without asking again for what found nothing.

Why: Adding or tidying a library (an anime library above all, where releases and subtitles differ) left its gaps to the next RSS sync or a Search all missing across every library. Waiting for the scan's matching first keeps episodes just found from being searched for as missing; leaving it to a button keeps scheduled scans from sending every library's titles to the indexers.
