Decision: Deluge is asked about downloads every 5 seconds while any is downloading, and every
60 seconds when none is; a grab wakes the follower at once, so a new download is followed
closely from its start. Imported torrents are still cleared once a minute.

Why: Progress only moved when Deluge was asked, once a minute, so a download of a few minutes
showed three or four jumps; asking about the torrents already followed is one cheap call, made
often only while there is progress to show, so an idle server asks no more than before.
