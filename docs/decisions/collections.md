Decision: A collection is a saved song filter (several genres, a span of years, only liked
songs) kept on the server per user, at most 50 each, named uniquely per user. It stores only
the filter, so the songs it shows are always worked out afresh for the listener: only what
they may see now, with their own likes. No one else can list, read or delete it.

Why: The same collection should be there on every browser, without any music listed in it
going stale or showing what a listener may no longer see; a filter stays small and private.
