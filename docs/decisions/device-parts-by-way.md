Decision: A household device on Melete's own tunnel may be given only parts that the way in it's being added through opens: through a way that opens only watch parties, no device can be added at all, since a device never reaches party. Adding devices stays open through every way, like one's own sessions and API keys, and the rule that a device added through another device's tunnel reaches no more than that one stays.

Why: A device is a new way in, with a fixed address of its own. Without this, signing in through a narrow way (a VPS opening only watch parties, where the sign-in page is reachable from the internet) let a stolen password become a device reaching the library, which that way was set up never to open.
