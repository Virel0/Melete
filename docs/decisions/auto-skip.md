Decision: Skipping recaps, intros and previews without a press is a per-user playback preference
(`auto_skip` on `/me/playback`, off by default), not a per-device one. With it on, the players
pass over each recap, intro and preview once a play, as it starts; credits are never skipped this
way, as the next episode is offered then.

Why: Melete already finds those parts for every app's Skip buttons, so only the choice to skip
without pressing is new; kept with the user, every app follows it alike, as with auto-play.
