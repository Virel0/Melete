Decision: Outside services lists only what talks to something outside the server, grouped by what it's for, each on a page of its own; Melete's own features, which send nothing anywhere, are set up on a Features page laid out the same way. The catalogue says each one's group, and the group says the page. A feature that sets off searches on outside services (a song's album, searched for on the indexers and Soulseek) stays with Outside services.

Why: Every service drawn open on one page made it very long, with the settings an admin came for hard to find. A short list with each one's state shows at a glance what's on and what's waiting for something, and keeping the features that send nothing anywhere apart keeps the page about what leaves the server.
