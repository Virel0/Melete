Decision: Someone a playlist is shared with to edit may edit it through the web and the API as the sync log lets them from a device: rename it, change its notes and picture, add, move and remove songs, add a song waiting to arrive, and change a smart playlist's rules, each written into their own log as one of their devices would, so it reaches the owner and everyone else it's shared with. Only the owner deletes it, files it in a folder (folders are each user's own) or shares it; someone it's shared with to listen to changes nothing.

Why: The web should do what the Aoide apps do, and the sync log already accepts an editor's changes from a device; refusing them on the web alone left editors without a way to edit outside their devices.
