Decision: An offline copy's seek-bar previews are its source file's, served under the copy's own download link like its subtitles. A copy keeps the size and date of the file version it was made from (taken when making starts), and its previews are offered only while the file is still that version, so their times are the copy's; a copy made before copies kept that, or of a file changed since, has none.

Why: A device keeping a copy shouldn't need a playback link it never plays just to fetch the previews. A copy is the whole file, so the source's preview times fit it as they are, but only for the version it was made from: after an upgrade or a replaced file they would point at the wrong moments.
