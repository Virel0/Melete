Decision: An admin can remove a title from the Make room page. Every regular file in its folder
(or its one loose file) moves to `.melete-trash/removed-<when>-<title>/` in its library, never
over anything and never following a link; each is recorded in the trash with the reason
`removed`, can be put back on its own (its folder made again), and is deleted 30 days later like
any trashed file. Nothing moves unless every video is still as it was scanned, and a move that
fails puts back what had moved. The title, its files and extras are gone from the library at
once, and a wanted title stops being monitored. The library is still never deleted from except
through the trash.

Why: Freeing space is the household's decision, made on purpose and undoable for a month, as an
upgrade's replaced file is. Moving the whole folder keeps a title's subtitles and artwork with
it, so putting it back restores it as it was; stopping monitoring keeps it from being downloaded
again straight away.
